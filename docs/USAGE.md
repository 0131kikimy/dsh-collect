# 使用手册

**这篇文档解决什么问题：** 插件装好之后，带你从零走完一次完整流程——打开面板、粘网址、采集、生成文件、找到成果，并说清楚面板上每个开关分别是什么意思。

> 还没装？先看 [安装指南](INSTALL.md)。文件生成出来打不开或格式不对，看 [格式说明](FORMATS.md)；操作报错看 [常见问题与排查](TROUBLESHOOTING.md)。

## 第 0 步：打开面板

1. 打开 DSH。
2. 在左侧边栏找到「采文」图标，点一下。
3. 主区域会打开「采文 · CollectKit」页面：顶部是标题、右侧是版本号和「刷新」按钮，下面是一张张卡片。
4. 如果页面一直空白或转圈，点右上角「刷新」；还不行就重启 DSH。

## 先认路：面板分 5 个区

| 区 | 位置 | 用来干什么 |
| --- | --- | --- |
| 顶栏 | 最上面 | 显示标题和版本号，点「刷新」重新读取状态 |
| 信息获取方式 | 第 2 块 | 5 个开关，决定插件能用哪些方式去取网页 |
| 采集 | 第 3 块 | 粘网址、点「开始采集」、看采集结果 |
| 生成文件 | 第 4 块 | 先选「导出对象」，选格式（9 个按钮），点「生成」，点「下载」 |
| 设置 | 最下面 | 改输出目录、单页最大字节、超时毫秒、图片上限、下载图片 |

## 信息获取方式：5 个开关分别是什么意思

| 开关 | 含义 | 默认 | 什么时候打开 |
| --- | --- | --- | --- |
| 原生联网 | 插件优先用 DSH 宿主自带的联网服务去取网页。宿主没提供时，这一行显示"不可用" | 开 | 一般保持开 |
| 直连抓取 | 宿主联网不可用时，插件自己直接访问网站 | 开 | 一般保持开（和上一项至少有一样开着） |
| 浏览器标签页 | 允许 AI 用浏览器工具读取你已打开页面的内容，**不移动鼠标**；面板本身不驱动浏览器 | 关 | 面板两路都抓不到、但网页在浏览器里能正常打开时 |
| 桌面操控 | 允许 AI 使用桌面操控类工具，会真的移动鼠标、敲键盘 | 关（硬拦截） | 只有确实需要时才开，且要先装好 computer 操控类插件 |
| MCP 工具 | 允许 AI 借用你已连接的 MCP 数据源插件的能力 | 关 | 你装了 MCP 数据源插件、想让它参与采集时 |

关于「桌面操控」，请务必看清这几点：

- 它**会动你的鼠标和键盘**，你正在做的事可能被打断，也可能误点到别的东西，所以风险等级是"高"。
- 默认关闭，而且关闭状态是**硬拦截**：就算 AI 自己想用桌面操控，插件也会直接拒绝，不会偷偷操作你的电脑。
- 要打开它，需要两个条件同时满足：你已经装了 computer 操控类插件（开关旁边的能力徽章会显示"可用/未安装"），以及在面板里手动把这个开关打开。
- 打开后如果不用了，建议再关回去。

补充两点，避免误会：

- 面板上的「开始采集」只用「原生联网」和「直连抓取」这两路。后三个开关是"给 AI 的授权开关"：面板两路都失败时，错误提示会告诉你打开哪一个，让 AI 用对应工具去取。
- 「原生联网」和「直连抓取」**不能同时关闭**：至少要留一路能真正取网页，否则保存设置时会被拒绝。

开关是**改动立即保存**的：点一下就会写入设置，不需要再点「保存设置」。如果保存失败，开关会自动弹回原来的状态，并在页面上给出提示——看到弹回就说明没保存上，检查一下 DSH 是否正常。

## 采集一次网页，只要 3 步

1. **粘网址。** 在「采集」区找到网址输入框，把网页地址粘进去。多个网址可以一行一个，也支持用逗号或空格隔开。
2. **点「开始采集」。** 按钮会进入加载状态，页面上显示"正在采集第 n/m 个"，等它走完。
3. **看结果列表。** 采集完成后，下方出现一行行结果，每行显示：标题、来源域名、字数、图片数、获取方式徽章、保存的相对路径。

结果行里还可以点「查看正文」展开预览——这是只读的，最多显示 4000 字符，用来快速确认"抓对了没有"，不是编辑器。

如果两路都取不到，结果行会给出错误原因和下一步提示（比如提示你打开某个开关、让 AI 用浏览器工具去取）。照着提示做就行，不用猜。

一次别粘太多网址：数量越多、越慢，也越容易被对方网站限制。建议一次 5 个以内，分批来。

✅ 检查点：你应该看到结果列表里至少有一行，显示标题、字数和图片数，并且没有红色错误提示。

## 生成文件：选对象 → 选格式 → 点「生成」

1. 在「生成文件」区，先看「导出对象」：下拉框里是这次采集成功的文章，默认选中最近一篇。想换一篇，就在下拉框里选，或者到上面的采集结果里点那篇文章的标题。
2. 点一下你想要的格式按钮（9 个：`docx`、`xlsx`、`pptx`、`pdf`、`md`、`html`、`txt`、`csv`、`json`）。当前选中的会高亮。
3. 点「生成」按钮。
4. 等一两秒，下方结果行会显示：文件名、大小，以及一个「下载」链接。点「下载」就能把文件存到浏览器默认的下载位置。

默认选中的格式是 `docx`（Word 文档）。每种格式适合什么场景、有什么限制，见 [格式说明](FORMATS.md)。

如果选了 `pdf` 却没有生成 PDF，而是得到了 `docx` 并附带一句提示，说明本机没找到可用的 PDF 转换引擎——这是插件自动降级，不是出错。需要什么条件见 [格式说明](FORMATS.md) 的 PDF 一节。

✅ 检查点：你应该在「生成文件」区看到生成结果行，显示文件名（以你选的格式后缀结尾）、大小和「下载」按钮。

## 文件到底存在哪

采集和生成的结果，默认都在**工作目录**下的 `采文输出/` 里，而且**每篇文章一个子文件夹**。结构大致是这样：

```text
C:\path\to\workspace\采文输出\
└─ 某篇文章的标题\
   ├─ index.md              正文（Markdown，开头有标题、来源网址、采集时间）
   ├─ meta.json             这篇的元信息
   ├─ 图片\                 下载下来的图片，按 001、002 编号
   └─ 某篇文章的标题.docx    你点「生成」得到的文件，默认也放在这篇的文件夹里
```

找文件的三条路：

1. 面板「设置」区顶部会显示当前的工作目录/输出目录完整路径；「输出目录」那一栏填的就是相对位置（默认 `采文输出`）。
2. 采集结果行里显示的"保存路径"是相对工作目录的路径，照着这个路径找。生成的文件默认就在这篇采集结果的文件夹里，和 `index.md` 放在一起。
3. 生成结果行里点「下载」，文件会直接进浏览器默认的下载位置，这是最不会找错的方式。

如果改了「输出目录」，新成果会存到新的位置，以前的老文件仍留在 `采文输出/`。注意：改设置要记得点底部的「保存设置」。

✅ 检查点：你应该能打开 `C:\path\to\workspace\采文输出`，看到至少一个以文章标题命名的文件夹，里面有 `index.md` 和 `图片/`。

## 设置区：5 个设置项怎么改

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 输出目录 | `采文输出` | 成果存哪里。只能填相对工作目录的目录名，不能填 `C:\` 开头的绝对路径，也不能用 `..` |
| 单页最大字节 | 8388608（约 8 MB） | 单个网页最多下载多大；超过会被截断，防止一个超大页面卡住 |
| 超时毫秒 | 20000（20 秒） | 单个网页最多等多久；网络慢可以调大 |
| 图片上限 | 20 | 每篇文章最多下载几张图片；图片太多可以调小 |
| 下载图片 | 开 | 关掉后只存文字，速度快、省空间 |

改完任何一项，都要点「设置」区底部的「保存设置」，看到保存成功的提示才算生效。这和上面的开关不一样：开关是点一下就存，设置项是点「保存设置」才存。

## 不想点面板？直接让 AI 帮你做

插件同时给 AI 提供了工具，你可以用日常说话的方式让它干活：

- 采网址：对 AI 说"**帮我采一下这个网址：https://example.com/article**"——AI 会调用 `collect_fetch`。
- 生成文件：接着说"**把刚才那篇存成 Word**""**存成 PDF**"——AI 会调用 `collect_export`。
- 改设置：也可以让 AI 调 `collect_settings`：读当前设置、改输出目录/图片上限/PDF 转换器，或者列出历史采集结果。

你可以一次把两件事说完："采这个网址，然后存成 xlsx 放到 `采文输出/` 里"。AI 会自己挑工具、自己按顺序做。

## 用之前、用之后的几个小建议

- **一次少粘几个网址**，5 个以内最稳；失败了单独重试，不要把一批全丢进去。
- **只采你有权保存的内容**。采集到的文章自己看没问题，公开转载要遵守原网站的版权和条款。
- **图片多的时候调小「图片上限」**，不然一次下载几十张大图会很慢。
- **定期清理 `采文输出/`**，它不会自动删除，攒久了会占空间。
- **桌面操控能不开就不开**，需要时打开、用完关掉。
