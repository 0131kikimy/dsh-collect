# 安装指南

**这篇文档解决什么问题：** 让你把「采文」插件装进 DeepSeek Harness，并且能确认它到底装没装成功——全程只需要点鼠标，不用写代码，也不用单独安装 Node.js。

> 装好之后怎么用，见 [使用手册](USAGE.md)；装的过程中卡住了，见 [常见问题与排查](TROUBLESHOOTING.md)。

## 装之前，先确认两件事

1. 打开 DSH，随便点几下，确认它能正常使用（不是白屏、不是一直转圈）。
2. 确认你的 DSH 有「插件」入口：一般在左侧边栏底部或设置里，点开能看到已安装插件列表和「添加」按钮。

如果找不到「插件」入口，先更新 DSH 到较新的版本，再回来安装。

## 方式一：在「插件」页用「添加」安装（推荐，最简单）

适合情况：你能拿到插件的仓库地址（一个 `https://github.com/...` 开头的网址）。

不同版本 DSH 的按钮名称可能略有差异，看到含「添加 / 安装 / 从地址安装」字样的入口就是它。

1. 打开 DSH，点开「插件」页。
2. 点「添加」（有的版本叫「安装插件」或「从地址安装」，意思一样）。
3. 出现一个输入框，把仓库地址粘进去：

   ```text
   https://github.com/0131kikimy/dsh-collect
   ```

   注意：这个地址里的 `<你的账号>` 是占位符，**不是让你原样粘贴**。要换成你实际拿到的仓库地址（例如别人发给你的 GitHub 链接）。粘之前先看一眼，把 `<`、`>` 和中文一起去掉。
4. 点「确认」或「安装」，等进度条走完。
5. 看到「安装成功」之类的提示后，**完全退出 DSH**：关掉窗口，再确认任务栏里也没有 DSH 的图标（必要时右键退出）。然后重新打开 DSH。
6. 打开后看左侧边栏：多出了一个「采文」图标。

如果「插件」页里找不到「添加」按钮，还可以直接对 AI 说"用插件管理器从 GitHub 安装和上面相同的地址"，AI 会帮你走同一个安装通道。

✅ 检查点：你应该看到左侧边栏出现「采文」图标；点一下，页面标题是「采文 · CollectKit」，右上角有版本号和「刷新」按钮。

## 方式二：从本地解压文件夹安装

适合情况：别人直接发给你一个压缩包（`.zip` 或 `.tgz`），没有仓库地址。

1. 把压缩包解压到一个你记得住的位置，比如 `C:\path\to\dsh-collect`。
2. 打开解压出来的文件夹，确认里面直接能看到这些内容：`package.json`、`lib`、`locale`、`cordis.patch.yml`、`icon.svg`。看到它们说明解压对了，没有多套一层文件夹。
   - 如果点进去只有一层同名文件夹，再点进去一层，找到 `package.json` 为止。
3. 打开 DSH 的「插件」页，点「添加」。
4. 选「从本地文件夹安装」（或「浏览…」后选择文件夹）。
5. 选中 `dsh-collect` 这个文件夹**本身**（就是里面有 `package.json` 的那一层），不要选它的上一层。
6. 点「确认」，等安装完成。
7. **完全退出 DSH 再重新打开。**
8. 看左侧边栏，出现「采文」图标。

## 方式三：手动放进 profile 的 node_modules，再用插件管理器添加

适合情况：上面两种方式都失败了，或者你用的是一个不联网的环境。这一步稍微麻烦一点，但仍然是复制粘贴。

1. **先完全退出 DSH**（关窗口 + 确认任务栏图标消失），不然文件会被占用。
2. 找到 DSH 的数据目录：
   - Windows：打开文件资源管理器，在地址栏输入 `%USERPROFILE%\.dsh` 后回车。默认数据目录就在这个位置；如果你改过 DSH 的数据目录，就打开你改过的那个。
   - 进去后依次进入 `profiles` → `desktop` → `node_modules`。`desktop` 是你当前正在用的 profile 名字，如果你用的是别的名字，就选对应的那个。
3. 把解压好的整个 `dsh-collect` 文件夹复制进 `node_modules`。复制完的路径形状应该是 `C:\path\to\dsh-profile\node_modules\dsh-collect`，里面能看到 `package.json`。
4. 重新打开 DSH。
5. 进入「插件」页，在列表里找到 `dsh-collect`，点「添加」或「启用」。
6. 再重启一次 DSH（或刷新页面），然后看左侧边栏。

## 装好之后，用 30 秒做一次自检

1. 左侧边栏点「采文」，面板能打开，标题是「采文 · CollectKit」。
2. 面板里从上到下能看到这些区：顶栏（标题 + 版本号 +「刷新」）、信息获取方式、采集、生成文件、设置。
3. 点「刷新」，页面不会报错。
4. 到「设置」区，能看到「输出目录」，默认填的是 `采文输出`。
5. 对 AI 说一句"用 collect_fetch 采一下这个网址"，AI 能认出这个工具（说明插件已加载）。

✅ 检查点：你应该看到面板五个区都在，并且「设置」区里「输出目录」一栏显示的是 `采文输出`。

## 卸载

1. 打开 DSH 的「插件」页。
2. 找到 `dsh-collect`，点「移除」或「卸载」。
3. 完全退出 DSH 再打开，左侧边栏的「采文」图标会消失。
4. 可选清理：删除数据目录下的 `dsh-collect` 文件夹（里面是插件保存的设置），以及工作目录下的 `采文输出/` 文件夹（里面是采集成果，删之前先确认不需要了）。

## 装不上？先看最常见的 3 个原因

1. **地址填错。** 占位符 `<你的账号>` 没换、多了空格、少了 `https://`，都会失败。
2. **没有重启 DSH。** 装完不重启，侧边栏不会出现图标，看起来像没装上。
3. **网络到不了 GitHub。** 公司网络、代理、断网都会让安装卡住或超时。

按顺序排查：

1. 回到「插件」页，看安装记录里有没有报错文字。把报错原文记下来。
2. 重新复制一次完整地址，确认开头是 `https://`，结尾是 `dsh-collect`，中间没有中文和空格。
3. 重启 DSH 后再看一次侧边栏；还是没有，就检查「插件」页里 `dsh-collect` 是不是被禁用了，点「启用」再重启。
4. 换一个网络（比如手机热点）重试安装；如果公司网络限制访问 GitHub，就把方式二或方式三的离线安装当作首选。
5. 仍然不行，按 [常见问题与排查](TROUBLESHOOTING.md) 第 1 条继续排查，并把「插件名是 `dsh-collect`、报错原文是什么、DSH 版本号是多少」一起告诉帮你的人。

✅ 检查点：你应该能说出失败卡在哪一步：找不到「添加」入口、地址报错、安装中卡住、还是装完没图标。

## 下一步

装好了就去 [使用手册](USAGE.md)，按 5 步走一遍：点图标 → 粘网址 → 开始采集 → 选格式生成 → 到 `采文输出/` 找文件。
